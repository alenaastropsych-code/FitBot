# Фит-бот Алёны

Telegram-бот для похудения: напоминания, вес, еда с подсчётом КБЖУ по фото, вода, зарядка, зал, прогулки, сводки за день и неделю.

## Что умеет

| Ты присылаешь | Бот делает |
|---|---|
| Число, например `79,3` | записывает вес, показывает изменение, среднее за 7 дней и цель недели |
| Фото еды (можно с подписью) или текст «2 яйца и гречка 150 г» | считает КБЖУ через нейросеть, добавляет в итог дня |
| `7500` или `5 км` | записывает прогулку |
| Кнопки 💧 +250 / +500 | добавляет воду |
| Кнопки 🤸 Зарядка / 🏋️ Зал | отмечает тренировку |
| 📊 Сегодня / 📈 Неделя | сводка |
| ↩️ Отменить еду | удаляет последнюю запись еды за сегодня |

**Напоминания (по Москве):** 7:43 — вес и зарядка · 15:00 — вода, если выпито меньше 0,8 л · 20:52 — итог дня и что не записано · воскресенье 19:47 — разбор недели.

## Запуск за 4 шага

### 1. Создать бота в Telegram
1. Открой [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Придумай имя и username (должен заканчиваться на `bot`).
3. Скопируй **токен** — это `BOT_TOKEN`.

### 2. Получить ключ нейросети (для подсчёта калорий)
1. Зарегистрируйся на [proxyapi.ru](https://proxyapi.ru) — оплата российской картой в рублях.
2. Пополни баланс на 300–500 ₽ — этого хватит надолго.
3. В личном кабинете создай API-ключ и скопируй его — это `AI_API_KEY`.

### 3. Залить код на GitHub
1. На github.com создай новый репозиторий, например `fit-bot` (лучше **Private**).
2. Add file → Upload files → перетащи `bot.py`, `requirements.txt`, `README.md` → Commit.

### 4. Запустить на bothost.ru
1. Создай нового бота, язык **Python**, подключи репозиторий `fit-bot`.
2. Главный файл: `bot.py`.
3. В переменных окружения добавь:
   - `BOT_TOKEN` — токен из шага 1
   - `AI_API_KEY` — ключ из шага 2
4. Запусти. Открой своего бота в Telegram и нажми **/start** — ты станешь его владельцем, чужие люди пользоваться не смогут.
5. Бот пришлёт твой Telegram ID. Добавь его в переменные как `OWNER_ID` — так владелец сохранится, даже если база сбросится при перезапуске.

## Дополнительные настройки

- `AI_MODEL` — модель (по умолчанию `anthropic/claude-haiku-4-5`, быстрая и дешёвая). Точнее, но дороже — Sonnet; точное имя модели смотри в каталоге ProxyAPI.
- `AI_BASE_URL` — адрес API. По умолчанию ProxyAPI. Если захочешь OpenRouter: `https://openrouter.ai/api/v1/chat/completions` и ключ в `AI_API_KEY`.
- `DB_PATH` — где хранить базу (по умолчанию `fitbot.db` рядом с ботом). Если на хостинге есть постоянное хранилище, укажи путь в нём, чтобы история не терялась при пересборке.

План по весу, нормы КБЖУ и время напоминаний задаются в начале `bot.py` (блок «настройки»).
